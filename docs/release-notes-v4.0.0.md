# YuiTodo v4.0.0

> 纯本地、无账号、零网络请求的 Android 任务管理应用。
> 本次为大版本更新：重复任务引擎重写、主页分区、日历、专注、习惯、统计升级，以及真机通知修复。

**版本信息**

| 版本 | 版本号 | 说明 |
|------|--------|------|
| 开源版 | `v4.0.0` (versionCode 15) | 发布到 Releases，不含自定义字体 |
| 完整版 | `v4.0.0.1` | 仅本地构建，含自定义字体，不公开分发 |

## ✨ 新功能

### 重复任务引擎（occurrence）

- 采用「模板 + 虚拟实例 + occurrence 例外」模型，不再为重复任务物化每日条目。
- 子任务完成状态按每次 occurrence 独立隔离，历史勾选不会串到今天。
- 日历、统计、主页统一按 occurrence 计算，只统计到今天，未来实例不虚增数据。

### 主页分区与手势

- 首页分为「逾期 / 今天 / 未来 / 今日完成」，折叠状态持久化。
- 左滑星标、右滑完成、长按多选，支持批量操作。
- 删除后顶部横幅「撤销」，也可在回收站恢复。
- 顶部筛选支持标签与状态混合筛选。

### 日历视图

- 月历按标签颜色打点，点击日期查看当日任务。
- 支持在日历中直接完成子任务。

### 专注模式

- 番茄钟 / 正计时两种模式，支持暂停、结束、休息。
- 专注结束自动记录，可查看历史会话。

### 习惯追踪

- 用重复任务承载习惯（每日/每周规则 + `is_habit` 标记）。
- 打卡、连续天数、本周进度、最近 30 天网格。
- 统计中可一键「排除习惯」。

### 统计升级

- 时间范围：7 天 / 30 天 / 90 天 / 1 年 / 全部。
- 今日进度、完成率、子任务完成率、连续天数、热力图、标签/星期/月份分布。
- 新增鼓励语与「统计时排除习惯」开关（默认包含习惯）。

### 示例数据

- 首次安装自动写入一组示例任务与习惯，涵盖分区、标签、子任务、重复、习惯、统计等场景，直接作为内置使用说明。
- 仅在任务表为空时写入，删除后不会再次出现，不影响老用户数据。

## 🛠️ 修复与改进

### 真机通知修复

- 修复 Release 包通知不触发：补充 R8/Gson 保留规则，解决 `Missing type parameter`。
- 清单补全 `ScheduledNotificationReceiver` / `BootReceiver`，重启后提醒仍在。
- 精确闹钟检测改用 `canScheduleExactNotifications()`，避免静默失败。
- 重复任务自动预排未来 7 天提醒，应用启动时自动重排。

### 通知样式增强

- 大文本样式（BigTextStyle）、任务颜色、`reminder` 分类、`PUBLIC` 可见性。
- 摘要显示应用名，横幅信息更完整。

### 真机 UI 适配

- 窄屏（354dp）顶栏自动收纳为「搜索 / 筛选 / 更多」，修复标题被 6 个图标挤掉、图标间距过大的问题。
- 日历 / 专注 / 统计 / 设置收进「更多」菜单。

### 体验打磨

- 页面转场、滑动跟手、触觉反馈、分区折叠动画。
- 任务卡片渐变、备注自适应、星标标记。

## 📦 安装

1. 下载 `YuiTodo-v4.0.0-opensource.apk`。
2. 在 Android 设备上允许「未知来源」安装。
3. 首次打开会自动生成示例任务与习惯，可随时删除。

**建议**：在系统设置中允许「闹钟和提醒」并关闭电池优化，可获得更精确的提醒时间。

## ⚠️ 已知限制

- 通知暂未实现自定义 RemoteViews 布局（与 Todoery 的完全体横幅仍有差异），后续评估通知库或平台通道方案。
- 多提醒时间点、每任务独立铃声、稍后提醒等仍在计划中。
- 仅支持 Android，纯本地存储，无云同步与账号体系。
